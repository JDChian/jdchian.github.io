# jdchian.github.io

JDChian 的個人作品集網站：https://jdchian.github.io

## 如何更新

- **專案**：編輯 `index.html` 底部 `<script>` 裡的 `projects` 陣列
- **技能**：編輯同一處的 `skills` 陣列
- **自我介紹 / 聯絡方式**：搜尋 `TODO` 修改
- **截圖**：放到 `images/` 資料夾，並在專案的 `image` 欄位填入路徑（例如 `images/project1.png`）

推送到 `main` 後，GitHub Pages 會在一兩分鐘內自動更新。
